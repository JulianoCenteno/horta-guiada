# Horta Guiada (protótipo)

- `index.html` — quiz de vendas + página de vendas (espaço do vídeo reservado), prévia do checkout com order bumps, upsells e downsells.
- `app/` — protótipo do aplicativo (PWA de arquivo único), pensado para o público 50+.
- `app/img/` — logo e imagens geradas no ChatGPT.

Publicado no GitHub Pages: https://julianocenteno.github.io/horta-guiada/

## Produtos dos order bumps
- `produtos/horta-guiada-projetos-premium.pdf` — Projetos Premium: tomate, morango e pimentão (12 páginas).
- `produtos/horta-guiada-kit-para-imprimir.pdf` — Kit para Imprimir: calendário, acidez, estações, ajuda rápida e 6 receitas (13 páginas).
- Acesso Família — tela dentro do app (menu Ajuda → Acesso Família).
